# PRIMORA

Vetor_ETL

Projeto acadêmico de desenvolvimento de um pipeline ETL para tratamento, limpeza e padronização de dados cadastrais de clientes da Distribuidora Vetor.

Sobre o projeto

O Vetor_ETL tem como objetivo melhorar a qualidade e a consistência dos dados cadastrais por meio de etapas de extração, transformação e preparação dos dados. O projeto contempla o tratamento de informações como CNPJ, telefone, CEP e data de cadastro, além da integração com APIs externas para consulta de CEPs.

Objetivos

Padronizar dados cadastrais.
Identificar informações inválidas ou inconsistentes.
Reduzir problemas durante o processamento dos dados.
Consultar informações de CEP por meio de APIs externas.
Separar registros tratados daqueles que precisam de revisão.

Tecnologias Utilizadas

**Python:** desenvolvimento da lógica de tratamento dos dados.
**Pandas:** leitura, manipulação e processamento de arquivos CSV.
**Expressões regulares (Regex):** validação e padronização de formatos.
**Requests:** comunicação com APIs externas.
**JSON:** armazenamento de dados em cache.
**Pytest:** execução de testes automatizados.
**Git e GitHub:** versionamento e gerenciamento do código.


Aprendizados

O desenvolvimento do projeto proporciona experiência prática com manipulação de dados, validação de informações, expressões regulares, integração com APIs, organização modular de código e testes automatizados.
